# Книжная полка

Локальный запуск из папки `main`:

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Откройте `http://127.0.0.1:8000/`. Добавляйте книги через `/admin/`. PDF-файлы открываются для чтения в браузере, TXT-файлы — прямо на странице, остальные загруженные форматы можно скачать. В режиме разработки обложки и книги хранятся в `media/`.

## Деплой на Render

В корне репозитория находится `render.yaml`. Он создаёт бесплатный web service и PostgreSQL для демонстрационного запуска.

1. Запушьте проект в GitHub или GitLab. Render подключается к Git-репозиторию; в этой папке git remote пока не настроен.
2. В Render выберите **New → Blueprint**, подключите репозиторий с этим `render.yaml` и примените конфигурацию.
3. В настройках Environment веб-сервиса задайте `ADMIN_USERNAME`, `ADMIN_EMAIL` и `ADMIN_PASSWORD`. На следующей сборке команда `ensure_admin` создаст администратора из этих значений; пароль хранится в Render, а не в Git.
4. Войдите по адресу `https://<имя-сервиса>.onrender.com/admin/` и добавьте книги.

Render Free подходит для показа друзьям, но имеет ограничения: сервис засыпает после периода без запросов, бесплатная база истекает через 30 дней, а загруженные обложки и книги хранятся во временной файловой системе и могут исчезнуть после перезапуска или деплоя. Для длительного использования потребуется платная база и постоянный диск либо внешнее хранилище файлов.
